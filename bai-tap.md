# my-new-project

Đây là dự án thực hành tạo Repository mới trên GitHub.

## Các lệnh Git đã sử dụng

- `git init`: Khởi tạo một Local Repository mới.
- `git remote add origin`: Kết nối Local Repository với Remote Repository trên GitHub.
- `git add README.md`: Đưa file README.md vào vùng staging.
- `git commit -m`: Lưu các thay đổi vào lịch sử Git.
- `git push origin main`: Đẩy các thay đổi từ máy tính lên GitHub.
